# Plugins

Набор пользовательских JS-плагинов для медиацентра [Lampa](https://github.com/immisterio/lampa).
Каждый файл подключается в Lampa как отдельный плагин (через URL к «сырому» файлу на GitHub) и работает независимо от остальных.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `continue_movies.js` | Отдельный ряд «Продолжить просмотр» только для фильмов (сериалы и уже просмотренное/брошенное исключаются из выборки). |
| `mob_rat.js` | Ряд оценок (IMDb, Кинопоиск, TMDB, Rotten Tomatoes, Metacritic, Letterboxd, Trakt, MyAnimeList) в карточке — показывается только на мобильных экранах (≤ 590px). Требует API-ключи MDBList и/или КиноПоиск, которые вводятся в настройках Lampa. |
| `no-anime.js` | Полностью скрывает аниме-контент (по жанру «Animation» + японскому языку/названию) из каталогов и подборок. |
| `parser-selector.js` | Переключатель Jackett-парсеров прямо из интерфейса Lampa — хранит список серверов и активный индекс, применяет `jackett_url`/`jackett_key`/`parser`. |
| `podborki.js` | Подборки контента по стриминговым сервисам (Netflix, Disney+, Кинопоиск HD, Start и др.) — глобальные и российские платформы. |
| `serials-skip` | Автопропуск заставок/интро в сериалах и аниме, используя базы TheIntroDB, AniSkip, Jikan и др. |

## Установка плагина в Lampa

В настройках Lampa: **Плагины → Добавить плагин** и указать прямую ссылку на `raw`-версию нужного файла из этого репозитория.

## Установка плагина `claude-seo` для Claude Code

Этот раздел не относится к Lampa — это инструкция по подключению стороннего плагина
[`claude-seo`](https://github.com/AgriciDaniel/claude-seo) к [Claude Code](https://claude.ai/code)
через маркетплейс плагинов. Команды выполняются в интерактивной CLI-сессии Claude Code (не в этом репозитории):

```
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup
```

1. `/plugin marketplace add AgriciDaniel/claude-seo` — добавляет GitHub-репозиторий `AgriciDaniel/claude-seo` как источник (маркетплейс) плагинов.
2. `/plugin install claude-seo@agricidaniel-claude-seo` — устанавливает сам плагин `claude-seo` из этого маркетплейса.
3. `/seo setup` — запускает команду настройки, которую предоставляет установленный плагин.

> **Важно.** `AgriciDaniel/claude-seo` — сторонний, независимо поддерживаемый маркетплейс, не связанный с этим репозиторием.
> Перед установкой проверьте, что доверяете источнику: установка плагина и запуск его команд (хуки, MCP-серверы, скилы)
> может выполнять произвольный код в вашей среде Claude Code.
